# MACD Adaptive

Websites, WhatsApp and automation for small businesses in Ireland. Plain language, accessible by default.

[![Website](https://img.shields.io/badge/Website-macd.ie-786883?style=flat-square)](https://macd.ie)
[![Demos](https://img.shields.io/badge/Sample_sites-demos.macd.ie-5E8298?style=flat-square)](https://demos.macd.ie)

## What we do

- **Websites** for local businesses, built to be fast, readable and easy to use on a phone.
- **WhatsApp and booking automation** so customers get a reply and a confirmed slot without the phone tag.
- **Accessibility checks** on every site we ship.

## Open source

- [smp-ucp](https://github.com/macd-adaptive-limited/smp-ucp) - SMP-UCP v0.1 proposal, request for feedback. Implementation and schemas are in progress.
